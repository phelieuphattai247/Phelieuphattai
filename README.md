# Phelieuphattai
Phế Liệu Phát Tài chuyên thu mua phế liệu tại TP.HCM và nhiều tỉnh thành trên cả nước, phục vụ khách hàng cá nhân, doanh nghiệp, nhà máy sản xuất, khu công nghiệp và công trình xây dựng. Các mặt hàng thu mua bao gồm đồng, sắt, nhôm, inox, dây cáp điện, máy móc cũ, phế liệu điện tử và các loại vật tư thanh lý khác.
